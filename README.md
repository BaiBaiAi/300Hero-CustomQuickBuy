# 300 英雄自定义快捷购买

在对局的装备界面增加六个自定义快捷购买槽，并保留一个可重复购买的单购槽。每位英雄的配置会分别保存，下次使用该英雄时自动加载。

## 下载与安装

下载 [Windows 安装器](dist/300Hero-QuickBuy-Installer.exe)。运行 EXE 即可，不需要安装 Python。

1. 退出游戏，确认 `300.exe` 已关闭。
2. 打开安装器，点击“浏览”，选择**当前电脑的游戏目录**。该目录应包含 `300.exe` 和 JMP 文件；盘符不必是 `F:`。
3. 可先点“查看状态”确认安装器找到了游戏资源，再点“安装并验证”。
4. 启动游戏，进入对局并打开商城。首次使用时，六个快捷购买槽为空，可将商城装备拖到槽位中设置。

安装器会在改动前备份原有脚本和 JMP 资源，备份位于游戏目录的 `custom_quickbuy_backups` 文件夹。重新安装不会清空已保存的英雄配置。

## 对局中怎么用

- 将商城装备拖到六个快捷槽中的任意一格，即可为当前英雄保存该格装备。单击已设置的槽位购买一件。
- 商城打开时，右键快捷槽可清空该格；商城关闭时只显示已配置的槽位。
- 预购槽上方还有一个单购槽，默认购买传送卷轴。也可拖入其他装备；单击或按 `O` 键购买，允许重复购买。
- 背包里已有的装备会在快捷槽上显示遮罩，避免重复购买；卖出后可再次购买。
- 每位英雄的配置分别保存。需要手动备份配置时，复制游戏目录下的 `external_lua/custom_quickbuy/heroes` 文件夹。

## 卸载

退出游戏后，打开同一个安装器，选择游戏目录并点击“卸载并备份”。安装器会恢复原 JMP 资源，并将本项目脚本、英雄配置和安装备份移到游戏目录旁的 `300Hero_quickbuy_uninstall` 文件夹。卸载后如需找回配置，可从该文件夹取回。

## 常见问题

**提示找不到 JMP 文件**：检查选择的是否为包含 `300.exe` 和 JMP 文件的游戏目录，而不是安装器所在目录。

**提示 `Expected one setup.lua JMP resource, found 0`**：安装器扫描到了 JMP 文件，但没有找到普通游戏所用的 `setup.lua`。先确认所选目录；若目录无误，可能是游戏更新改变了资源路径或包结构。安装器不会改动 PVE、体验服的同名资源。

**提示资源校验、初始化位置或容量错误**：安装器会停止写入。可检查游戏文件是否完整；游戏更新若改变了脚本结构，可能需要更新安装器。它不会因为客户端版本 MD5 变化而单独拒绝安装。

**提示游戏正在运行**：完全退出游戏后再安装或卸载。

如需排查问题，请提供安装器的完整报错文字，以及游戏目录中 JMP 文件的名称。实际商城操作建议先在训练对局中测试。
